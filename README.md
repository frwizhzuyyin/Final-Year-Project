# Final-Year-Project
A web-based Clinical Decision Support System (CDSS) that uses Logistic Regression to predict the need for Continuous Renal Replacement Therapy (CRRT) in patients with sepsis. Built with Flask, MySQL, Bootstrap, and the MIMIC-IV dataset to support early clinical decision-making in intensive care units (ICUs).
This Final Year Project presents a Web-Based Clinical Decision Support System (CDSS) for predicting the need for Continuous Renal Replacement Therapy (CRRT) among patients with sepsis. The system integrates a Logistic Regression machine learning model trained using the MIMIC-IV dataset with a Flask-based web application, MySQL database, and Bootstrap user interface. It enables healthcare professionals to input clinical parameters, receive CRRT risk predictions, manage patient records, and generate clinical reports to support timely and informed decision-making in intensive care units (ICUs).
